04 / CRIPTOGRAFIA APLICADA

AES-GCM e integridade de dados

Web Crypto API · HTTPS

Escreve uma mensagem de demonstração e cifra-a com AES-256-GCM. A chave aleatória permanece apenas na memória da página e não é exportável; se atualizares a página, não será possível recuperar a mensagem cifrada nessa sessão. Nunca introduzas palavras-passe ou dados reais sensíveis.

SHA-256 serve aqui para observar uma impressão digital de dados; não é um método adequado para armazenar palavras-passe.

Resultado

Aguardamos uma operação…

  • AES-GCM: confidencialidade e integridade autenticada.
  • Nonce: valor aleatório de 96 bits para esta mensagem.
  • RSA: abordado no projeto Java original, mas não reproduzido como criptografia caseira.
