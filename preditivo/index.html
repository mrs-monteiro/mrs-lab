07 / PROJETO FINAL DE ENGENHARIA INFORMÁTICA

UABBet — do projeto final de curso ao MRS Predictive Lab

O UABBet foi o meu projeto final de curso de Engenharia Informática na Universidade Aberta. O trabalho explorou bases de dados, preparação de informação e classificação em Python. Esta demonstração é uma implementação educativa independente: reúne um conjunto sintético reproduzível, treino de modelos em períodos anteriores e avaliação de probabilidades em períodos posteriores.

PreparaçãoForma recente e força relativa, calculadas antes de cada encontro.
ModelosRegressão logística, Random Forest e referências simples.
AvaliaçãoSeparação por temporadas, matriz de confusão, log loss e Brier.

O UABBet original inclui outras funcionalidades; estes resultados não são os resultados da sua defesa ou de previsões reais. A importação CSV usa um modelo Elo educativo, não treina automaticamente novos modelos de machine learning.

08 / UABBET · METODOLOGIA E PROVENIÊNCIA

O projeto académico por detrás do laboratório

O UABBet é o projeto final de curso que inspira este espaço. A demonstração pública usa dados gerados para aprendizagem e não reproduz integralmente o motor, os datasets ou os resultados académicos originais.

Dados e preparação

Organização de eventos desportivos, equipas, competições, resultados e mercados. A qualidade e a cronologia dos dados condicionam qualquer análise.

Classificação

A exploração académica inclui regressão logística e Random Forest. Nesta página são usados classificadores e referências demonstrativas em dados sintéticos.

Probabilidade e avaliação

Interpretação probabilística, análise bayesiana no âmbito original e medidas de erro na demonstração. Uma previsão não equivale a um resultado garantido.

Separação responsável

Treino e previsão requerem conjuntos distintos no tempo. O laboratório não mistura agenda real com probabilidades sintéticas para sugerir apostas.

O que é original e o que é demonstrativo?

UABBet original: projeto académico de software, bases de dados, análise e modelação, preservado fora da publicação. LAB público: interface de aprendizagem independente, com dataset fictício, visualizações e agenda externa. Nenhuma previsão real é atribuída aos modelos sem validação.

09 / PROJETO FINAL DE CURSO · TECNOLOGIAS E FORMATOS

Como foi desenvolvido o UABBet?

O projeto académico integrou programação, bases de dados, tratamento de informação, visualização e aprendizagem automática. As tecnologias abaixo foram identificadas nos ficheiros do UABBet original; a interface deste LAB é uma implementação pública independente.

Python · linguagem principal

Scripts de aquisição/preparação, análise de futebol e basquetebol, construção de datasets, treino e utilização dos modelos e geração de gráficos.

Streamlit · interface do projeto

Aplicação de exploração e apresentação de tabelas, visualizações e resultados, apoiada por pandas e matplotlib.

PostgreSQL e SQL · dados

Estruturas relacionais para eventos, equipas, competições e outros dados do domínio; ligação em Python com SQLAlchemy e psycopg2.

Ciência dos dados e ML

NumPy, pandas, scikit-learn, matplotlib e seaborn para preparação, modelação e visualização. Inclui regressão logística, Random Forest e análise bayesiana.

O que utiliza o MRS Predictive Lab público?

O laboratório publicado usa HTML, CSS e JavaScript para a interface e interação, e JSON para a agenda e dados sintéticos. Não executa o código Python original do UABBet no navegador nem disponibiliza os modelos treinados ou as bases de dados privadas.

Esta descrição baseia-se no arquivo do projeto académico. Não implica que todas as bibliotecas tenham sido utilizadas em todas as funcionalidades nem apresenta métricas do trabalho final como sendo previsões reais atuais.

🧠 O que estás a aprender?

Uma previsão com 60% de probabilidade não significa certeza. Em muitas repetições semelhantes, resultados menos prováveis também acontecem.

As percentagens são geradas para este exercício, não são estimativas do UABBet. Acertar em poucas rondas não demonstra que exista uma estratégia rentável.
