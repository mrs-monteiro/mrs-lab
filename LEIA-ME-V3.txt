ODDS (OPCIONAL, DESATIVADO POR PREDEFINIÇÃO)
-------------------------------------------
O The Odds API oferece um plano grátis com créditos mensais, sujeito a limites.
O código já inclui adaptador opcional para odds h2h de 8 competições, região EU.
NÃO ativa nem publica odds por defeito.

Só depois de obter autorização de uso/redistribuição do feed:
1. Criar GitHub Actions secret "ODDS_API_KEY" com chave de https://the-odds-api.com/.
2. Criar GitHub Actions repository variable "ODDS_PUBLISH_ENABLED" com "true".
3. Executar o workflow e verificar entradas com bookmaker, origem e updated_at.

A associação do feed às partidas é conservadora: exige equipas iguais e horários
com diferença máxima de seis horas, preferindo NÃO apresentar odds a misturar jogos.
Ausência de odds não é um defeito da interface: pode não haver partida compatível,
dados disponíveis para a competição, ou licença para a divulgação.

MODELOS PREDITIVOS REAIS
-----------------------
Esta versão não inventa probabilidades. Os jogos com model=null mostram
"Sem previsão validada".
Foi preparado um contrato para modelos treinados/validados externamente:

"model": {
  "status": "validated",
  "name": "Nome do modelo",
  "training_end": "2026-09-30T00:00:00Z",
  "evaluated_at": "2026-10-01T00:00:00Z",
  "validation": { "n": 100, "log_loss": 0.99, "brier": 0.58 },
  "probabilities": { "1": 0.45, "X": 0.29, "2": 0.26 }
}

ATENÇÃO: o exemplo de formato NÃO É uma previsão pronta a usar. Só preencher
com artefactos reais de modelos e métricas produzidos em validação cronológica.
Para basquetebol e NHL são usadas duas classes: "1" e "2" (mercado h2h).
O navegador rejeita previsões sem metadados de avaliação e com treino após o jogo.

SEGURANÇA E LIMITAÇÕES
----------------------
- O script faz até 8 pedidos API-Sports/dia (2 dias x 4 APIs) na execução diária.
- Se um dia falhar, preserva dias válidos e fontes anteriores.
- Futebol, Basquetebol (NBA incluída), NHL, Hóquei em patins.
- Hóquei em patins continua alimentado separadamente por fonte oficial.
- NBA é processada via API-NBA mas apresentada sob sport=basketball e league=NBA.
- A API NHL é de hóquei no gelo, não de hóquei em patins.
- Chaves guardadas exclusivamente no GitHub Secrets, nunca num ficheiro público.
- Não incorporar previsões sintéticas no calendário real.
- Confirmar previamente termos de utilização e republicação de qualquer feed.
