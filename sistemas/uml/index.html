01 · Um cenário, três perspetivas

Seleciona um diagrama. As vistas apresentam uma representação pedagógica simplificada, não uma especificação formal completa.

Os atores representam papéis externos ao sistema. Os casos de utilização descrevem objetivos funcionais, não operações de base de dados.

Modelo conceptual orientado a objetos: classes não são automaticamente tabelas SQL. As associações são apresentadas de forma reduzida.

A sequência descreve a ordem conceptual das mensagens, não chamadas HTTP reais nem uma implementação em produção.
