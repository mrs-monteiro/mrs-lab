01 / FUNDAMENTOS

O que é, e o que não é um agente?

Nível inicial · sem conhecimentos prévios
💬

Chatbot

Responde a perguntas. Pode dar orientações sem executar ações externas.

Exemplo: explicar um erro HTTP 503.
⚙️

Automatização clássica

Segue regras fixas definidas antecipadamente. É previsível quando o processo está bem definido.

Exemplo: abrir um ticket quando um limiar é ultrapassado.
🧠

Agente de IA

Usa um modelo para interpretar objetivos, selecionar ferramentas e adaptar os próximos passos, dentro de limites.

Exemplo: investigar um incidente e propor ações com evidências.
🔌

MCP

Protocolo para disponibilizar ferramentas e contexto a sistemas de IA. Não é, por si só, um modelo nem um agente.

Exemplo: consultar entidades e ações num ambiente autorizado.
Ideia-chave: um fluxo com vários blocos e nomes de «agentes» não prova que exista IA. Numa solução real precisamos de um modelo, ferramentas com permissões, validação de respostas, tratamento de erros e rastreabilidade.

04 / HOW TO · PRIMEIRO AGENTE

Do conceito a um protótipo seguro

Roteiro orientador · sem instalar software agora

Plano progressivo

0 de 6 passos concluídos

Exemplo de contrato de ferramenta

Uma ferramenta de leitura não deve permitir, por acidente, eliminar ou alterar dados. A autorização tem de ser verificada no servidor, não apenas na prompt.

ferramenta: consultar_incidente
entrada: { referencia: string }
permissão: incidentes.ler
saída: resumo_minimizado
alterações: não permitidas
registo: obrigatório

Num serviço real, acrescentaríamos autenticação, limites de consulta, redacção de dados pessoais, testes e auditoria.
