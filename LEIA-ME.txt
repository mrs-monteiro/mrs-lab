MRS AGENT STUDIO V2.0 — ORIGINAL MRS MONTEIRO
===============================================

OBJETIVO
Aprender a construir 1, 2 ou 3 agentes com prompts, funções, modelos,
regras, auditoria e simulação animada. O cenário é inteiramente fictício.

PUBLICAÇÃO NO GITHUB PAGES
Repositório: https://github.com/mrs-monteiro/mrs-lab
Atualizar apenas:
  agentes/index.html
  agentes/js/agents.js
Criar:
  agentes/js/studio.js
  agentes/css/studio.css
Não alterar o index.html principal do mrs-lab, nem os outros laboratórios.
O CSS original agentes/css/agents.css fica como está.

A V2 substitui expressões referentes a plataformas comerciais por
cenários originais MRS de ServiceDesk, Acessos e Alterações em APIs fictícias.
O website público funciona totalmente em modo Simulação sem custos.

EXECUÇÃO OPCIONAL COM OPENAI API — APENAS LOCALMENTE
Nunca colocar OPENAI_API_KEY no GitHub nem no browser.
O backend incluído NÃO deve ser colocado online no GitHub Pages.
Na pasta do pacote no Windows 11, abrir PowerShell e executar:

  py -m venv .venv
  .\.venv\Scripts\Activate.ps1
  pip install -r backend_local/requirements.txt
  $env:OPENAI_API_KEY="A_TUA_CHAVE_PRIVADA"
  $env:MRS_ENABLE_API="1"
  $env:MRS_MAX_REQUESTS="12"
  python backend_local/server.py

Abrir APENAS http://127.0.0.1:8787/ ; selecionar OpenAI API no Studio.
O servidor escuta só em 127.0.0.1 e não expõe qualquer ferramenta de escrita.
Interromper com Ctrl+C; a chave existe apenas nessa sessão PowerShell.
Se PowerShell bloquear Activate.ps1, usa .venv\Scripts\python.exe sem ativação.
A configuração do token de ambiente na sessão não é guardada no repositório.

FATURAÇÃO API
Uma subscrição ChatGPT não equivale a saldo da API. A faturação de API
é separada. No portal da API, adicionar método de pagamento e créditos.
Consultar: https://platform.openai.com/settings/organization/billing/overview
Podem existir créditos promocionais. Confirmar preços e limites antes.
A compra inicial pré-paga mínima documentada é 5 USD; recarga automática
pode ficar ativada por omissão: desativar se não a quiseres.
Estabelecer limites de utilização e alertas também no dashboard da API.
O limite MRS_MAX_REQUESTS é local à execução do servidor, não é um
limite financeiro absoluto; reiniciar o servidor reinicia a contagem.

MODELOS PERMITIDOS
 - gpt-5.4-mini (primeiro recomendado para testes)
 - gpt-5.4
Os custos variam conforme tokens e modelo. O número de tokens no Studio
é devolvido pela API, não é uma previsão de preço.

SEGURANÇA
- Usar APENAS dados fictícios em demonstrações públicas.
- Não fornecer logs de produção, dados pessoais, credenciais nem segredos.
- Não ligar a sistemas empresariais reais sem autorização e revisão.
- A demonstração não modifica sistemas, nem fornece ações automáticas.
- A aprovação humana é ilustrativa. A execução de ações reais exigiria
  backend autenticado, autorização no servidor, auditoria persistente e testes.
- Para serviço público real, usar autenticação, rate limit, proxy, HTTPS,
  observabilidade, controlos de despesas e autorização formal.
