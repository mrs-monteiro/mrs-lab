01 / CONDIÇÕES & CICLOS

Descobre o número secreto

Estou a pensar num número de 1 a 100. Usa as pistas para acertar com o menor número de tentativas.

🎯 Missão: descobre o número secreto.

Começa por 50. A cada tentativa, o jogo diz-te se deves procurar acima ou abaixo do número escolhido. O intervalo vai ficando mais pequeno.

Intervalo possível: 1 a 100

Dica: tenta sempre o número do meio do intervalo para reduzir as opções.
Faz a primeira tentativa!
Tentativas: 0Histórico: —
Ver a lógica em Python
import random

segredo = random.randint(1, 100)
while True:
    tentativa = int(input("Número: "))
    if tentativa < segredo:
        print("É maior!")
    elif tentativa > segredo:
        print("É menor!")
    else:
        print("Acertaste!")
        break

Exemplo de consola para estudo. O jogo desta página é implementado em JavaScript, não executa Python.

Escolhe uma resposta e verifica.

💡 A explicação

`if` testa uma condição. Se a tentativa for menor que o segredo, a mensagem indica que o número é maior.

Código correto:

segredo = 42
tentativa = 30

if tentativa < segredo:
    print("É maior!")

02 / LISTAS & ALGORITMOS

Sorting Challenge

Observa como o Bubble Sort compara elementos adjacentes e troca valores até ordenar a lista. Avança um passo de cada vez ou executa a demonstração completa.

🎯 Missão: ordenar os números do menor para o maior.

Carrega em «Próximo passo». O programa compara duas barras vizinhas e troca-as quando a primeira é maior. Experimenta até ficares com 2, 3, 4, 5, 7, 8, 9.

Por comparar Em comparação Posição final
Prepara-te para ordenar os valores.
Comparações: 0Trocas: 0
Ver a lógica em Python
valores = [7, 3, 9, 2, 5]
for fim in range(len(valores) - 1, 0, -1):
    for i in range(fim):
        if valores[i] > valores[i + 1]:
            valores[i], valores[i + 1] = valores[i + 1], valores[i]
print(valores)

Ordenação por trocas adjacentes. Não é uma recomendação de desempenho para listas grandes.

Missão Robô

Programa o robô com instruções simples. Constrói uma sequência, executa-a passo a passo e tenta chegar à bandeira sem tocar nas paredes.

Ver a lógica em Python
# Exemplo conceptual de uma função
# Cada comando altera a posição ou direção.
def executar(comandos):
    for comando in comandos:
        if comando == "F":
            print("Avançar")
        elif comando == "L":
            print("Virar à esquerda")
        elif comando == "R":
            print("Virar à direita")

executar(["F", "R", "F"])

`for` percorre cada elemento da lista, permitindo tratar um comando de cada vez.

comandos = ["F", "R", "F"]

for comando in comandos:
    print(comando)
